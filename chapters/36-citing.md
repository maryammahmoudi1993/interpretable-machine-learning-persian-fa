# فصل ۳۶: ارجاع به این کتاب

> **عنوان اصلی:** Citing this Book  
> **منبع:** [https://christophm.github.io/interpretable-ml-book/cite.html](https://christophm.github.io/interpretable-ml-book/cite.html)  
> **نویسنده:** Christoph Molnar  
> **مترجم:** مریم محمودی

---

اگر این کتاب برای وبلاگ، مقالهٔ پژوهشی یا محصول شما مفید بوده، سپاسگزار می‌شوم اگر به این کتاب ارجاع دهید. می‌توانید به این شکل به کتاب ارجاع دهید:


```
Molnar, C. (2025). Interpretable Machine Learning:
A Guide for Making Black Box Models Explainable (3rd ed.).
christophm.github.io/interpretable-ml-book/
```

یا از مدخل bibtex زیر استفاده کنید:

```
@book{molnar2025,
  title={Interpretable Machine Learning},
  subtitle={A Guide for Making Black Box Models Explainable},
  author={Christoph Molnar},
  year={2025},
  edition={3},
  isbn={978-3-911578-03-5},
  url={https://christophm.github.io/interpretable-ml-book}
}
```

> <span style="color:#7C3AED">**توضیح مترجم:**</span> قالب ارجاع و مدخل bibtex بالا عیناً از متن اصلی آمده‌اند و عمداً ترجمه نشده‌اند، چون باید برای ارجاع به کتاب اصلی دقیقاً به همین شکل (با عنوان انگلیسی) استفاده شوند. اگر از این ترجمهٔ فارسی در نوشته‌ای استفاده می‌کنید، مرجع علمی همچنان کتاب اصلی Christoph Molnar است؛ در صورت تمایل می‌توانید جداگانه به این ترجمه هم اشاره کنید. شکل دقیق ارجاع به ترجمه در متن اصلی توضیح داده نشده است.

من همیشه کنجکاوم بدانم روش‌های تفسیر در صنعت و پژوهش کجا و چگونه به کار می‌روند. اگر از کتاب به‌عنوان مرجع استفاده می‌کنید، عالی می‌شد اگر چند خطی برایم بنویسید و بگویید برای چه. این البته اختیاری است و فقط کنجکاوی خود من را ارضا می‌کند و گفت‌وگوهای جالب را برمی‌انگیزد. ایمیل من chris@christophmolnar.com است
